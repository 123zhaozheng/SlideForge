# 高质感视觉组件词典（Component Library）

无论是在 **模式 B 撰写整页高定蓝图提示词**，还是在 **模式 A 规划原生 PPTX 排版结构** 时，模型听不懂「做高级一点」「排版好看点」这种空话，它只听得懂**具体的组件结构与视觉语法**。直接组合下列成熟组件，彻底告别纯文字 bullet 墙与平庸三等分白框。

---

## 1. 强视觉锚点组件（每页只放 1 块）

### Hero 实心渐变锚点卡（Hero Anchor Card）
- **结构**：圆角 10px，饱满主色微渐变填充（如 `#0F2A56 → #1B4FD8` 或 `#C81832 → #A30D24`）+ 极轻柔底部投影。
- **内部三段**：顶部半透明细白边胶囊小标签 + 中部大号加粗白色主口号 / KPI / 跃升箭头（如 `从 0 到 1 ↗ 规模跃升`）+ 底部 1–2 行白色精炼阐释。
- **用途**：一页只放 1 块，瞬间抓住视线重心。

### 模块化虚线 Bento 容器（Dashed Bento Container）
- **结构**：`1px dashed #CDD3DB` 细虚线圆角矩形外框，纯白或极浅微透底，内边距均匀充足。
- **顶栏**：左上角小号实心色块编号（如 `01`）+ 深炭黑粗体区标题，右上角极简主色细字副标。
- **用途**：把多个子卡片或图表优雅归组，兼具严谨秩序感与轻盈呼吸感。

## 2. 替代「纯文字列表」的 6 种高阶信息组件

### ① 横向结构化能力带（Horizontal Capability Strip）
- **替代**：平庸的 3 列竖排空心大白框。
- **结构**：白底细实线圆角长条，内部严格左中右三段：
  - **左段（20%）**：实心色块（随行递进主色→二色→三色），内嵌等宽大号数字 `01` + 竖线 + 粗体关键词（如 `建底座`）。
  - **中段（42%）**：1–2 行核心举措说明（深灰 `#4E5969`）。
  - **右段（38%）**：专属微可视化图示（见下方微图示组件）。

### ② 咨询级主色表头矩阵表（Executive Matrix Table）
- **结构**：主色实底白字通栏表头 + 浅色（L4 衬底）列头或左侧业务域竖色块 + 纯白内容格 + 极细浅灰横线（禁用粗黑网格线）。
- **技巧**：单元格内「代码/指标加粗标主色 + 名称深炭黑 + 说明次级灰」，高密度依然极易扫读。

### ③ 扁平分层架构栈（Flat Layered Architecture Stack）
- **结构**：自上而下 3–4 层扁平圆角横条，居中以极细实线双向箭头（↑↓）连接。
- **视觉区分**：入口层用主色实心横条（白字），核心中台层用白底 + `1.5px` 强调色描边 + 内部一行优势胶囊，底层存储用左右并列浅灰微卡。严禁 3D 塑料圆柱、厚重黑阴影与花哨渐变。

### ④ 通栏双阶段演进轨道（Dual-Stage Chevron Ribbon）
- **结构**：横跨全宽的浅底虚线容器，左端竖排主色标签块（如 `演进目标`），主体为左右两段柔和浅色大箭头色块（Chevron），中间以双右箭头 `》` + 过渡文字串联。
- **用途**：承载「近期试点 → 规模推广」「阶段一 → 阶段二」，同时锁住页面底部视觉重心。

### ⑤ 逻辑微图示（Micro-Visuals — 放在能力带右侧或卡片内部）
- **2×2 胶囊标签网**：4 枚浅底圆角胶囊，左侧带小圆点，展示四大分类/四大维度。
- **3 阶递进微流程**：由深到浅三枚圆角胶囊 + 细箭头串联（如 `采集 → 治理 → 赋能`），下方细横线标注总称。
- **3 节点闭环引擎**：三角形排布的 3 枚圆角胶囊，由柔和弧形双向箭头首尾相连（如 `业务反馈 ⇄ 策略迭代 ⇄ 成效评估`）。
- **带左色条微卡**：白底细框 + 左侧 `3px` 彩色竖条 + 极简线性矢量图标 + 右上角状态胶囊（如 `每日同步`）。

### ⑥ 顶部/底部注记条（Takeaway / Note Strip）
- **结构**：无多余边框，仅左侧 1 枚小主色圆点 + 单行清晰深灰说明小字（用于补充数据口径、前提条件或关键结论）。
- **原则**：仅在正文确实有重要限定口径或核心结论时添加，禁止硬编空洞口号。

## 3. 真实图片与插图槽位组件（Photo & Illustration Slots）

当页面需要展示**实拍照片、产品/系统截图、荣誉证书、高管头像或主题插图**时，不要让文字去硬挤画面，而是为其分配独立槽位：
- **圆角卡片槽位（`shape="rounded"`, `fit="cover"`）**：最常用于现场照片、系统界面截图、定制场景插画，自动居中裁切不留白边，配细边与柔阴影，底部可加 `9.5pt` 浅灰图注。
- **圆形头像/徽章槽位（`shape="circle"`, `fit="cover"`）**：适用于团队介绍、标杆人物、圆形核心视觉锚点。
- **原生虚线占位槽位（`img_path=None`）**：用户暂时未提供图片时，直接在版式中留出浅灰虚线框 + 清晰标签（如 `待放入：平台界面截图 / 现场实拍图`），确保整页构图完整且后续在 PowerPoint 中一键可替换。

# 模式 B · 整页高定视觉蓝图提示词与槽位规范（Blueprint Prompts SOP）

当用户选择 **模式 B（先出高设计感整页蓝图 → 确认审美后再 1:1 复刻为原生可编辑 PPTX）** 时，先用 `scripts/generate_blueprint.py` 画出杂志级/咨询级整页蓝图 `blueprints/slide-XX.png`。

**核心价值**：蓝图阶段只需极低成本即可预览整页构图、配色、呼吸感与视觉锚点；满意后再把蓝图作为 `style_ref` 拆批生成无文字组件并 4 层复刻为 100% 原生可编辑 PPTX——兼具 **AI 顶级艺术指导审美** 与 **PowerPoint 真可编辑交付**。

---

## 一、出蓝图前的 3 项设计决策

1. **读懂品牌与审美参考**：
   - 用户提供**企业母版底板图** → Agent 先用读图工具逐像素记下顶栏、底栏、Logo 与标题样式（字体/字号/位置/编号格式）。**硬铁律：底板原标题只学样式，文字必须 100% 替换为本页标题，严禁照抄底板原标题。**
   - 用户提供**历史优秀 PPT（`.pptx`）** → 先用 `scripts/render_pptx.py` 渲染成逐页 PNG，挑选最具代表性的 1–2 页作为 `--ref` 风格参考图（仅借鉴配色、留白与微组件工艺，严禁抄袭其具体业务文字/水印/数据）。
   - 无任何参考图 → 从 `references/design-systems.md` 选定 1 套匹配主题体系，或按用户口述推导 4 阶品牌色板。
2. **反平庸版式节奏（`references/layout-archetypes.md`）**：
   - 每页从 `A1`–`A10` 中选定明确原型，遵循**相邻异构律**（连续两页绝不用同一种版式）与**单锚点法则**（每页仅 1 个重色视觉重心）。
   - 文字全部组件化，从 `references/component-library.md` 挑选高阶组件，消灭三等分大白框与纯 bullet 列表墙。
3. **确认真实图片 / 插图槽位（`slots`）**：
   - 遇到需要 100% 保真的**实拍照片、产品/系统截图、证书奖杯、用户自备插图**，或用户想**预留空白位置后续手动放图**，在 `blueprint_manifest.json` 的该页下声明 `slots`。
   - `generate_blueprint.py` 会自动生成**透明橙色角标骨架图**送入 `/v1/images/edits`，强制模型在该区域留白避让，并把精确英寸坐标写入 `blueprint_metadata.json`，供后续复刻阶段由 `pptx_kit.add_image_slot()` 原生无缝填入！

## 二、大师级五段蓝图提示词模板（`blueprint_prompts/slide-XX.txt`）

每页蓝图提示词由 Agent 亲自精写，按以下五段组织：

```text
【区块一 · 底板或全局风格约束】
- 有底板时：严格使用图片1作为唯一 16:9 母版底板，顶部/底部装饰与 Logo 像素级不变；左上角标题严格沿用底板字体/字号/位置/配色，但标题文字必须替换为本页标题，严禁复制底板原标题。
- 无底板时：16:9 横版宽屏，纯净画布，采用 {设计体系名称} 与 4 阶色板（L1 {hex} / L2 {hex} / L3 {hex} / L4 {hex} / 正文 #1F2329 & #4E5969）。
- 若有参考图：仅借鉴参考图的构图留白、色阶层次与微组件质感，严禁抄袭其标题、水印、地图或无关文字。

【区块二 · 版式原型与视觉组件设计】
- 本页版式原型：{A1~A10 代号及空间切割比例，如左 34% Hero 锚点 + 右 62% 三行横向能力带}
- 唯一视觉锚点：{明确哪 1 个区块使用实心主色或重表头}
- 视觉语法：优先开放式杂志留白、极细 1px Hairline 分割线、1px 虚线 Bento 分区与咨询级微组件（来自 references/component-library.md），杜绝无意义的“大框套小框”与 3D 塑料感。

【区块三 · 本页页眉设置】
- 页眉主标题：{本页完整主标题}
- 副标题 / 核心导语（可选）：{1 句高管 3 秒能懂的核心结论}

【区块四 · 本页完整正文（忠实原意，禁止空洞套话）】
{按区块结构化排布的完整标题、数据、指标与精炼要点}

【区块五 · 严格禁止项】
- 禁止复制底板原标题文字；禁止照抄参考图中的无关文字或水印；
- 禁止平庸三等分白框堆砌；禁止草书艺术字与低对比浅灰正文；
- 禁止额外添加页码、日期栏或多余装饰贴纸。
```

## 三、`blueprint_manifest.json` 规范与槽位示例

详见 `examples/blueprint_manifest.sample.json`。每页可按需配置 `slots`：

```json
{
  "slides": [
    {
      "number": 1,
      "title": "平台架构与核心实景",
      "prompt_file": "blueprint_prompts/slide-01.txt",
      "image_file": "blueprints/slide-01.png",
      "slots": [
        {
          "id": "product_screenshot",
          "position": "右侧",
          "source": "assets/platform_ui.png",
          "label": "平台实景界面截图"
        }
      ]
    }
  ]
}
```

- `position` 支持语义方位（`"右侧"` / `"左侧"` / `"右上"` / `"右下"` / `"底部"` / `"中央"` / `"right"` / `"left"`）或精确归一化比例坐标 `"x,y,w,h"`（如 `"0.58,0.18,0.36,0.62"`）。
- `source` 为用户提供的本地图片路径；若用户**暂时没图、仅预留槽位**，将 `source` 留空 `""` 即可，复刻为 PPTX 时调用 `pptx_kit.add_image_slot(..., img_path=None, placeholder_label=label)` 自动生成精致的原生虚线占位槽位。
- **试水确认原则**：多页任务先跑 `--only 1,2` 生成前 1–2 页蓝图给用户亲眼确认审美与构图，确认无误后再批量生成其余蓝图并进入 1:1 可编辑复刻！
